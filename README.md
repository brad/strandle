# Strandle

Strandle is a word game that mixes Wordle's colored probe guesses with NYT Strands' themed letter web.

## Project Structure

- `src/`: Source files written in TypeScript and CSS
  - `src/index.html`: Main HTML entry point
  - `src/style.css`: Styles for the application
  - `src/types.ts`: TypeScript interfaces and types
  - `src/puzzles.ts`: Daily puzzle definitions
  - `src/main.ts`: Game logic, rendering, and interaction handling
- `dest/`: Built production static assets generated by Vite (`dest/index.html`, etc.)
- `docs/`: Project documentation
  - `docs/puzzle-generator-guide.md`: Guide for creating and adding new puzzles

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

`npm run dev`

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
